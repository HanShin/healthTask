# 운동 모션 제작 계획

운동 영상은 한 번에 여러 개를 대량 생성하지 않는다. 현재 루틴 사용 빈도와 장비 재사용성을 기준으로 한 운동씩 `레퍼런스 → 동작 정의 → 6개 자세 → 접촉 근접 화면 → 루프 영상 → 앱 검수`를 완료한다.

## 제작 순서

1. `flat-dumbbell-press` 플랫 덤벨 프레스 — 완료
2. `one-arm-dumbbell-row` 원암 덤벨 로우 — 완료
3. `shoulder-press` 숄더프레스 — 완료
4. `hammer-curl` 해머 컬 — 완료
5. `dumbbell-goblet-squat` 덤벨 고블릿 스쿼트 — 완료
6. `tabata-finisher` 로우 임팩트 버피·마운틴 클라이머·맨몸 스쿼트 — 완료
7. `dumbbell-romanian-deadlift` 덤벨 루마니안 데드리프트 — 완료
8. `dumbbell-bulgarian-split-squat` 덤벨 불가리안 스플릿 스쿼트 — 완료
9. `plank` 플랭크 — 완료
10. `push-up` 푸시업 — 완료, 손바닥 지지 보정본 사용자 승인 (2026-08-31)

1~4는 기본 `덤벨 밀기·당기기` 루틴, 5·7~9는 기본 `덤벨 하체 빌드` 루틴 순서다. 6은 사용자가 별도로 선택한 타바타 피니셔이며 한 가이드 안에 세 동작을 제공한다. 10은 플랭크 검수 후 사용자가 선택한 운동이다. 이후 운동은 실제 루틴 사용 빈도를 다시 확인해 순서를 갱신한다.

## 재사용 규칙

- 모든 운동은 승인된 스쿼트 사람형 메시·의상·리그와 같은 조명·플랫폼을 사용한다.
- 서 있는 동작은 스쿼트의 발 target과 스튜디오 구도를 출발점으로 삼는다.
- 덤벨 운동은 플랫 덤벨 프레스의 덤벨 규격과 검수된 손 그립 basis를 재사용한다.
- 벤치 지지 운동은 플랫 덤벨 프레스의 1.22 × 0.30 m 벤치를 재사용하되 등·가슴 접점은 운동별로 다시 계산한다.
- 장비 에셋은 재사용해도 IK pole, 관절 가동 범위, 장비 경로 수치는 복사하지 않고 운동별 레퍼런스에 맞춰 다시 정한다.
- 각 운동은 `docs/motions/{EXERCISE}.md`, Blender 원본, 생성 스크립트, 6개 자세, 필요한 접촉 근접 화면, 정면·측면 MP4를 함께 보존한다.
- 루프 영상은 정면·측면 모두 30 fps, 240 프레임, 정확히 8초로 출력한다.
- 앱 연결은 `GuideDialog`의 운동 ID별 raw 리소스 매핑에 한 항목씩 추가한다.
