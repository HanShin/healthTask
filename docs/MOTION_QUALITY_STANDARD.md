# 운동 모션 품질 기준

- 기준 버전: 1.0
- 확정일: 2026-08-21
- 기준 샘플: 사람형 하이바 바벨 스쿼트

이 문서는 `오늘운동`에 새 3D 운동 가이드를 추가하거나 기존 모션을 수정할 때 반드시 적용하는 완료 기준이다. 스쿼트 샘플에서 사람 비율, 장비 접촉, 손 그립을 여러 차례 수정하며 확인한 문제를 반복하지 않는 것이 목적이다.

새 모션은 아래 체크리스트를 모두 통과하기 전까지 앱용 최종 영상으로 간주하지 않는다.

## 1. 레퍼런스와 동작 정의

- 실제 사람이 수행하는 정면과 측면 레퍼런스를 각각 한 개 이상 확보한다.
- 가능하면 시작, 중간, 최대 가동 범위가 모두 보이는 영상을 사용한다.
- 레퍼런스 URL과 관찰한 핵심을 생성 스크립트 또는 운동별 작업 문서에 기록한다.
- 원본 영상을 복사하거나 앱에 포함하지 않고, 자세와 타이밍을 관찰하는 용도로만 사용한다.
- 제작 전에 다음 항목을 문장으로 확정한다.
  - 발 또는 신체의 고정 접점
  - 관절이 이동하는 방향과 최대 가동 범위
  - 몸통과 척추의 기준
  - 장비의 실제 이동 경로
  - 시작 자세로 돌아오는 방법과 반복 구간

## 2. 인체와 리깅

- 임시 막대 인형이 아니라 최종 사람형 메시와 실제 사용할 의상으로 검수한다.
- 팔·다리 길이, 어깨·골반 폭, 손과 발 크기가 과장되지 않았는지 확인한다.
- IK pole angle은 정면과 측면에서 따로 확인한다. 한 시점에서만 자연스러운 값은 사용하지 않는다.
- 발바닥, 손, 등처럼 장비나 바닥과 닿는 부위는 뼈 중심선이 아니라 메시 표면 두께를 기준으로 배치한다.
- 깊은 자세에서 의상 메시가 벌어지거나 피부를 관통하지 않는지 확인한다.
- 루트 이동과 척추 회전은 월드 공간 기준으로 검토해 프레임 사이의 예상치 못한 비틀림을 막는다.

## 3. 장비와 접촉

- 봉, 덤벨, 벤치, 케이블 등은 사람 크기에 맞는 실제 규격에 가까운 치수로 만든다.
- 장비 중심을 뼈 좌표에 그대로 놓지 않는다. 피부·의상 표면과 장비 반지름을 함께 계산한다.
- 접촉하는 신체 부위는 장비와 함께 움직이는 별도 target으로 제어한다.
- 시작·중간·최대 가동 범위에서 다음을 모두 확인한다.
  - 장비가 몸을 관통하지 않는다.
  - 손이나 몸이 장비에서 뜨지 않는다.
  - 관절이 장비를 따라 비정상적으로 꺾이지 않는다.
  - 장비 경로가 레퍼런스와 일치한다.

### 장비 충돌 자동 검증

- 벤치, 의자, 랙처럼 몸을 지지하는 장비는 생성 스크립트에서 최종 변형 메시 기준의 충돌 검사를 실행한다.
- 피부뿐 아니라 실제 렌더에 사용하는 상의·하의·신발·머리카락을 모두 검사 대상에 포함한다.
- 패드만 확인하지 않고 프레임, 다리, 바닥 지지대까지 장비의 모든 고정 부품을 collider로 등록한다.
- 뼈 좌표나 원본 메시가 아니라 armature와 modifier가 적용된 월드 공간 메시를 사용한다.
- 시작·중간·최대 자세 중 한 프레임이라도 교차 삼각형이 발견되면 저장과 렌더를 중단한다.
- 표면 접촉은 허용하지만 메시 관통으로 접촉을 표현하지 않는다. 렌더 오차를 고려해 눈에 띄지 않는 작은 표면 간격을 둔다.

### 봉을 잡는 손의 필수 기준

- 손가락을 단순히 주먹 모양으로 접는 것은 그립으로 인정하지 않는다.
- 손바닥의 3D basis를 다시 계산해 검지에서 소지로 이어지는 축이 봉의 길이 방향과 평행해야 한다.
- 손목은 전완과 자연스럽게 이어지고, 손바닥은 봉 표면으로 향해야 한다.
- 검지·중지·약지·소지는 각기 다른 관절 각도를 사용해 봉 위에서 시작하여 앞면과 아래쪽을 감싼다.
- 엄지는 검지 쪽에서 그립을 잠그며 `OK` 표시처럼 빈 고리를 만들지 않는다.
- 손가락 관절과 손끝 위치를 봉 중심·반지름과 비교하고, 메시가 눈에 띄게 관통하지 않는지 근접 렌더로 확인한다.
- 정면만으로 승인하지 않는다. 정면, 사선, 후면 근접 화면에서 같은 그립으로 보여야 한다.

현재 스쿼트의 통과 기준 이미지는 다음 파일이다.

- `design/motion/previews/human_squat_grip_front.png`
- `design/motion/previews/human_squat_grip_angle.png`
- `design/motion/previews/human_squat_grip_rear.png`

## 4. 운동 자세 검수

각 운동은 최소한 다음 여섯 장의 정지 프레임을 만든다.

- 정면 시작 자세
- 정면 중간 자세
- 정면 최대 가동 범위
- 측면 시작 자세
- 측면 중간 자세
- 측면 최대 가동 범위

정지 프레임에서 다음 항목을 확인한다.

- 좌우 관절이 의도하지 않게 비대칭이 아니다.
- 무릎, 팔꿈치, 손목이 해부학적으로 불가능한 방향으로 꺾이지 않는다.
- 척추와 목이 동작에 맞는 중립 범위를 유지한다.
- 발이나 고정 접점이 미끄러지지 않는다.
- 장비와 신체 접촉이 모든 깊이에서 유지된다.
- 실루엣만 보아도 어떤 운동인지 식별된다.

장비 접촉이나 손동작이 있으면 여섯 장 외에 해당 부위의 정면·사선·후면 근접 렌더를 추가한다.

## 5. 애니메이션과 루프

- 정지 프레임 승인 후에만 전체 영상을 렌더링한다.
- 영상 길이를 5초처럼 하나의 값으로 고정하지 않는다. 한 반복의 시작·중간·최대 자세를 사용자가 식별할 수 있도록 운동별로 정한다.
- 시작 자세와 최대 가동 범위는 각각 약 1초 이상 유지하고, 이동 구간은 실제 운동의 통제된 속도로 보여준다.
- 전체 프레임에서 발 미끄러짐, 관절 튐, 메시 관통, 장비 이탈을 확인한다.
- 시작과 종료 자세가 일치해 자동 반복 시 점프가 없어야 한다.
- 내려가기, 정지, 올라오기 속도가 실제 동작과 유사해야 하며 기계적으로 일정하지 않아야 한다.
- 장비 접촉 target과 신체 IK는 같은 타임라인을 사용해 프레임 지연이 생기지 않게 한다.

## 6. 렌더와 앱 리소스

- 기본 출력은 정면과 측면 각각 720 × 720, 30fps, H.264, 무음 MP4다.
- 카메라, 조명, 배경과 플랫폼은 현재 스쿼트 샘플의 시각 체계를 기준으로 통일한다.
- 앱에서는 Media3로 자동 반복하며 정면·측면 전환 후 재생이 정상이어야 한다.
- 파일 이름은 `{exercise}_front.mp4`, `{exercise}_side.mp4` 형식을 사용한다.
- Blender 원본과 재생성 스크립트를 함께 보존해 영상만 수동 교체하지 않는다.
- 사용한 사람형·의상·소품의 라이선스를 확인하고 저장소의 고지 문서에 반영한다.

## 8. 스쿼트 기준 구현

현재 품질 기준이 된 구현은 다음 위치에 있다.

- 생성 코드: `tools/blender/generate_human_squat_sample.py`
- Blender 원본: `design/motion/squat_human_sample.blend`
- 단계별 미리보기: `design/motion/previews/human_squat_*_{top,mid,bottom}.png`
- 그립 근접 기준: `design/motion/previews/human_squat_grip_{front,angle,rear}.png`
- 앱 영상: `app/src/main/res/raw/squat_front.mp4`, `app/src/main/res/raw/squat_side.mp4`

스쿼트 구현의 재사용 가능한 핵심은 다음과 같다.

- 발 target과 무릎 pole을 분리한다.
- 골반 이동과 척추 회전을 월드 공간 control로 나눈다.
- 바벨은 신체 뼈가 아니라 등 표면 두께를 포함한 별도 경로를 사용한다.
- 손의 basis를 봉 축에 맞춰 재구성한다.
- 손가락마다 다른 굽힘 값을 사용하고 장비 반지름을 기준으로 접촉을 검증한다.

다른 운동은 스쿼트의 숫자를 그대로 복사하지 않는다. 같은 검수 절차와 완료 수준을 유지하되, 장비 규격·접촉점·관절 각도는 운동별 레퍼런스와 모델 크기에 맞춰 다시 계산한다.
