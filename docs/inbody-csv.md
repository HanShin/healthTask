# 인바디 CSV 가져오기

`인바디 → 측정 기록 → 인바디 CSV 가져오기`에서 인바디 앱이 내보낸 파일을 선택합니다. 측정 건수, 값, 장비, 시간대를 확인하고 저장합니다. 파일은 휴대폰에서만 읽으며 외부 서버에 전송하지 않습니다. UTF-8(BOM 포함), UTF-16, CP949 CSV를 지원하고 5MB·5,000회 측정·128열·셀당 4,096자로 제한합니다.

## 보존 범위

- 날짜, 측정장비와 43개 지표를 지원합니다. 핵심 6개 외에 근육량, BMI, 기초대사량, 인바디 나이, 부위별 근육·지방·세포외수분비, 복부지방률, 허리둘레, 내장지방 단면적, 체수분·세포내/외수분, 균형 코드, 다리근육, 단백질·무기질·골무기질량·체세포량, SMI, 전신위상각을 포함합니다.
- 모든 열의 원본 이름·문자열을 저장합니다. 새로 생긴 미지원 열, 수치로 해석할 수 없는 값, `-` 등 미측정 표시도 상세 보기와 백업에 남습니다. 소수 자릿수·단위는 원본 표시를 따릅니다. 비율을 %로 바꾸거나 근육량을 골격근량으로 대체하지 않습니다.
- `상체하체 / 상체좌우 / 하체좌우`는 의미를 추측하지 않는 **원본 코드**로 표시합니다. 0도 보존하지만 연속 수치처럼 추이 그래프에 넣지 않습니다. 값이 없는 항목은 0으로 만들지 않습니다.
- 숫자로 읽을 수 있는 지표는 기존 체성분 테이블에도 저장되어 추이와 분석 내보내기에 포함됩니다. 변화 그래프·CSV 카드·내보내기 모두 같은 날의 여러 측정을 각각 보존합니다. 그래프에서 하루 대표값으로 합치거나 출처가 다른 기록을 덮어쓰지 않습니다.

## 변화 그래프

인바디의 `변화` 탭에는 인바디 점수·기초대사량을 먼저, 이어 체중·골격근량·체지방률과 다른 저장된 수치를 세로 카드로 표시합니다. 각 카드의 가로 그래프를 넘기며 점을 누르면 날짜·수치가 말풍선에 표시되고 점선이 선택한 위치를 가리킵니다. `측정 기록` 탭에는 CSV 가져오기·직접 입력·캡처·전체 원본·수정/삭제 기능이 있습니다.

- `최근`은 항목별 최근 10회 측정, `전체`는 저장된 모든 측정입니다. 전체 기록도 가로 스크롤로 살펴보며 화면에 필요한 점만 그려 긴 이력을 지원합니다. 1/3/6개월 기간 선택과 하루 대표값 방식은 이 카드 화면으로 교체했습니다.
- 가로축은 **측정 순서의 등간격**이며 실제 시간 간격을 뜻하지 않습니다. 같은 날짜가 여러 번 나올 수 있고 각 측정점을 별도로 선택할 수 있습니다. 세로축은 변화가 보이도록 조정한 항목별 개별 눈금으로 정상·목표 범위나 항목 간 절대 크기 비교용이 아닙니다.
- CSV 말풍선은 가져올 때 보존한 현지 시각을 초 단위로 표시합니다. 휴대폰 시간대가 바뀌어도 CSV 원본 시각은 유지합니다. 날짜만 있는 직접 입력·캡처에는 임의의 시간을 표시하지 않습니다. 점 누르기 또는 이전/다음 화살표로 기록과 출처를 확인합니다.
- `표시 항목`에서 값이 있는 지표를 표시/숨길 수 있습니다. 하나 이상 선택해야 하며 취소 시 기존 선택을 유지합니다. 최근/전체 및 숨긴 항목은 기기에 저장되며 앱 재시작 후 유지됩니다. 숨김은 원본 삭제가 아닙니다. 균형 원본 코드와 값이 없는 지표는 그래프에 넣지 않습니다.
- 카드의 `처음 대비`는 현재 최근/전체 범위의 마지막 값에서 첫 값을 뺀 차이이며 체지방률의 차이는 `%p`입니다. 1회는 점 하나만 표시합니다. 곡선은 측정점을 연결한 시각 표시일 뿐 중간 날짜의 값을 생성하거나 추정하지 않습니다. 전체 원본은 CSV 기록과 백업에 그대로 남습니다.

## 시각과 중복

CSV의 초 단위 측정 시각과 장비명을 기록 ID의 기준으로 삼습니다. CSV에는 시간대가 없으므로 가져오기 확인 화면에서 휴대폰 시간대를 기본 제안하고 사용자가 변경할 수 있습니다. 원본 현지 시각과 선택한 시간대·UTC 시각을 모두 보존합니다. 서머타임 전환으로 존재하지 않거나 두 번 존재하는 시각은 자동 보정하지 않고 거부합니다.

같은 시각·장비를 다시 가져오면 새 측정으로 만들지 않습니다. 이미 있는 값은 보존하고, 누락된 값과 새 열만 추가합니다. 다른 값이 충돌하면 기존 값을 유지하고 충돌 개수를 알립니다. 최초 선택한 시간대와 출처 파일명도 유지합니다. 파일 내부 중복 측정, 열 수 불일치, 날짜 오류, 깨진 따옴표 등은 저장 전 파일 전체를 거부합니다. 쓰기는 트랜잭션으로 처리합니다.

CSV 원본과 숫자 기록의 불일치를 막기 위해 CSV 측정은 항목별 수정·삭제 대신 **측정 기록 전체 삭제**를 제공합니다. 수정된 원본으로 교체하려면 해당 측정을 삭제하고 다시 가져옵니다. 휴대폰의 원본 CSV 파일은 삭제하지 않습니다. 직접 입력·캡처·외부 연동 기록은 별도로 유지합니다.

## 저장·백업

Room v7의 `inbody_records` 테이블에 원본 측정 정보를 저장합니다. 이전 러닝·센서·인바디 테이블은 비파괴 마이그레이션으로 유지합니다. 숫자 기록의 `externalRecordId`가 원본 측정 ID를 가리킵니다.

백업 v5는 `inBodyRecords`와 기존 전체 복원 데이터를 포함하고 v1~v4 가져오기도 지원합니다. 분석 v3는 `inBodyRecords[].rawFields`를 JSON 객체로 제공하고 숫자별 이름·단위는 `bodyMeasurements`에 포함합니다. v5 복원 시 원본과 숫자 기록의 일치 여부를 검증하며 분석 영역의 파생 수치는 복원하지 않습니다. 이전 앱 버전으로 다운그레이드하지 마세요.
